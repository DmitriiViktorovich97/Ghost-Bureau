# Призрачное бюро

Веб-приложение для оператора бюро переселения привидений. Подбирает места обитания
для заявок, объясняет решение, показывает конфликты и формирует финальный отчёт.

## Хостинг

Приложение развёрнуто на **SnapDeploy** (free tier).

### Важно: холодный старт

На бесплатном тарифе контейнер **засыпает** после ~15 минут неактивности.
При первом открытии страницы после паузы может быть:

- **долгая загрузка** — от 20 секунд до 2 минут;
- **ошибка 502/504** — это нормально, контейнер поднимается;
- **пустая страница** — обновите через 30 секунд.

Что делать: подождите, обновите страницу, попробуйте снова. Второй и последующие
запросы будут быстрыми, пока контейнер активен.

Если через 2–3 минуты не открылось — контейнер упал, смотрите логи в дашборде SnapDeploy.

## Быстрый старт

```shell
git clone <repo-url> ghost-operator
cd ghost-operator

docker compose build --no-cache
docker compose up -d
```
**Приложение будет доступно по адресу http://localhost:8080**

Первичная настройка
После первого запуска выполните миграции с тестовыми данными:

```shell
docker compose exec app php artisan migrate:fresh --seed
```

## Как работает подбор
Каждое место оценивается по формуле: база 100 + сумма бонусов и штрафов
от правил. Если срабатывает хотя бы один блокер место считается
неподходящим, независимо от суммы.

***Блокеры (жёсткие конфликты):**

место переполнено

дедлайн переселения просрочен

нужно что-то, чего в месте нет (чердак, отсутствие зеркал, отсутствие людей)

**Бонусы и штрафы (мягкие):**

+20 за чердак, +15 за тишину/темноту/сырость, +10 за отсутствие зеркал

−15 за несоответствие температуры, −25 за недостаток сырости, −30 за свет/шум

Тревожность ≥ 7: +10, если место тихое и тёмное; −20, если шумное.


## Тесты
Всего 5 файлов, покрывают сценарии из ТЗ:

tests/Unit/ConditionResultTest.php — DTO результата правила

tests/Unit/RuleProviderTest.php — реестр правил

tests/Unit/GhostMatcherTest.php — формула подбора, блокеры, capacity, дедлайн

tests/Unit/LocationTest.php — occupied/free/isFull

tests/Feature/GhostControllerTest.php — HTTP-сценарии (пустой список, автораспределение, ручной конфликт)

```shell
docker compose exec app php artisan test
```
